# Campus Event Management System

A full-stack web application where students of The University of Lahore can view and register for university events (seminars, workshops, sports, competitions, conferences and society activities).

## Installation

```bash
git clone https://github.com/QURSAM-70179225/campus-event-management.git
cd campus-event-management

# Back end
cd backend
npm install
npm run dev

# Front end (new terminal)
cd frontend
npm install
npm run dev
```
